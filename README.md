# 🎮 Case Bot

Бот для открытия кейсов с подарками в Telegram.

## Команды
- /start - Главное меню
- 🎰 Кейсы - Открыть кейс
- 👤 Профиль - Баланс
- 💰 Пополнить - Крипто-пополнение
- 🎁 Инвентарь - Твои предметы
- 📤 Вывести - Вывод подарков

## Деплой
1. Залей на GitHub
2. Подключи Render
3. Добавь BOT_TOKEN в переменные
4. Запускай!
